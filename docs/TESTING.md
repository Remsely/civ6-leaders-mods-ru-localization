# Как протестировать мод локально

Пилотный перевод: **JFD's Russia: Ivan IV** (`src/JFD_Russia_IvanIV`). Все шаги ниже одинаковы для любого другого мода из `src/`.

## Что нужно

- Civilization VI с дополнениями Rise and Fall и Gathering Storm (их требует мод Ivan IV).
- Подписка в Steam Workshop на **JFD's Russia: Ivan IV** (id `1307470417`) и на его зависимости. Если мод стоит у вас в игре, всё уже есть.
- Язык интерфейса игры — русский (`DisplayLanguage ru_RU` в `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\AppOptions.txt`; у вас так и есть).
- Python 3.10+ (только стандартная библиотека, ничего ставить не нужно).

## 1. Проверить перевод без запуска игры

Из корня репозитория:

```powershell
python tools/civ6loc.py validate
```

Проверка ловит: опечатки в тегах, непереведённые строки, потерянные `[ICON_…]`, `[NEWLINE]`, `{LOC_…}`, неверное число падежных форм у названий, а также изменение GUID исходного мода после его обновления. Код возврата `1` означает ошибку.

## 2. Установить мод в игру

```powershell
python tools/civ6loc.py install
```

Команда сама прогонит проверку, соберёт `dist/RuLocalization_LeadersAndCivs/` и скопирует его в
`%USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\Mods\RuLocalization_LeadersAndCivs`.
Если путь у вас другой, задайте переменную окружения `CIV6_MODS_DIR`.

В сборку попадают только переводы со `"status": "ready"` в `meta.json`. Чтобы проверить черновик, добавьте `--drafts`.

Удалить мод из игры: `python tools/civ6loc.py uninstall`.

## 3. Включить моды в игре

**Игру нужно полностью перезапустить**, если она была открыта во время `install`: список модов читается при старте.

1. Главное меню → **Дополнительный контент** → **Моды**.
2. Включите **«Русская локализация модов лидеров и цивилизаций»**.
3. Убедитесь, что включён и сам **JFD's Russia: Ivan IV**. Без него перевод намеренно не подгружается (так работает условие `ModInUse` в `.modinfo`).
4. Нажмите «Принять» и вернитесь в меню.

## 4. Что смотреть в игре

| Где | Что должно быть по-русски |
|---|---|
| Одиночная игра → Создать игру → выбор лидера (Россия → Иван IV) | имя лидера, особенность «Третий Рим», уникальный юнит «Стрельцы», повестка «Царь всея Руси» |
| Экран загрузки партии | текст «Вы, царь Иван, стоите на пороге…» |
| Цивилопедия → Лидеры → Иван IV | подзаголовок, цитата, биография, советы |
| Цивилопедия → Юниты → Стрельцы | описание и история |
| Дипломатия с ИИ-Иваном (или любым лидером, если ИИ играет им) | реплики приветствия, объявления войны, мира и т. д. |
| Окно дипломатии с Иваном IV (оценка отношений) | «Иван IV уважает ваши военные усилия» и подобные строки повестки |
| Падежи | фразы вроде «Иван IV объявил войну…» должны склоняться правильно |

Быстрый способ проверить всё сразу, не играя партию: создайте партию с вашим лидером Иваном IV, откройте Цивилопедию и посмотрите страницы лидера и юнита.

## 5. Если что-то не так

Логи лежат в `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\`:

- `Modding.log` — подключился ли наш мод и его `UpdateText`; ошибки загрузки файлов и критериев.
- `Localization.log` — ошибки разбора текстов.
- `Database.log` — ошибки базы данных.

Симптомы:

| Симптом | Вероятная причина |
|---|---|
| Всё по-английски | наш мод или Ivan IV не включён; игра не перезапущена после `install`; язык игры не русский |
| В тексте видны `LOC_…` | тег переведён, но исходный мод не загрузился, либо в `ru_RU.xml` опечатка в теге (поймает `validate`) |
| Мод не виден в списке | неверная папка в `CIV6_MODS_DIR` или ошибка в `.modinfo`; смотрите `Modding.log` |
| Часть строк английская | эти строки не вошли в перевод; `python tools/civ6loc.py validate` покажет, каких тегов не хватает |

## 6. Цикл правки перевода

1. Правите `src/<мод>/ru_RU.xml`.
2. `python tools/civ6loc.py validate`.
3. `python tools/civ6loc.py install`.
4. Перезапускаете игру (список модов читается при старте).

Подробнее о структуре и добавлении новых модов: [TRANSLATION_GUIDE.md](TRANSLATION_GUIDE.md).
